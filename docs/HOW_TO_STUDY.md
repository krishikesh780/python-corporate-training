# How to study this repo (read order)

## Before Week 1

1. Read [README.md](../README.md) — structure & setup  
2. Run **one-time setup:** `scripts\setup.bat`  
3. Activate env: `.venv\Scripts\activate`  
4. Skim [CURRICULUM.md](CURRICULUM.md) — full roadmap  

## Daily loop (each training day)

1. **Open the day file** (e.g. `week2/day3.py`)  
2. Read the top block: **PYTHON CLASSROOM** + **PYTHON RECALL**  
3. Run: `python week2/day3.py`  
4. Do **P1–P5** at the bottom of the same file (write answers in a notebook or `exercises/solution/`)  
5. Optional: same topic in `quick_revision/` for interview cram  

## After each week

- Run that week’s **capstone project** (see week `README.md`)  
- Week 5 end: [Assessment](../week5/Assessment.txt) + feedback session  

## Where to read what

| Goal | Read |
|------|------|
| Full day map | [CURRICULUM.md](CURRICULUM.md) |
| One-page per week | `week1/README.md` … `week5/README.md` |
| Practice questions (text) | `exercises/*.txt` |
| Fast revision / interview | `quick_revision/README.md` |
| Project business rules | `week4/day5/project3/docs.md`, `week5/Project5/docs.md`, etc. |

## Before interview (fast)

1. `interview_prep/INTERVIEW_ALL.txt` (5 min)  
2. `interview_prep/weekN.txt` for that role  
3. `interview_prep/MOCK_30MIN.txt` self mock  

## After Week 5 (AI job track)

1. Read `week6/README.txt`  
2. Follow **project1** → **project2** → GitHub push (`STEPS.txt` in each folder)  
3. Read `week6/INTERVIEW.txt` before mocks  

~1 hour/day is enough.
